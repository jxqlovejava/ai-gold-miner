## ATR 移动止盈规则

### 参数
- 时间周期：日线
- ATR 周期：14 日
- 乘数：2.5

### 公式
```
移动止盈价 = max(持仓期间最高价 - 2.5 × 14日ATR, 成本价)
```

## 快速检查（每次交易前/收盘后 4 问）

2. 48小时内有高影响事件吗？
3. 空仓状态下会在这个价格操作吗？
4. 机构资金在流入还是流出？
