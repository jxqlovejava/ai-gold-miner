# 金价分析报告固定模板

> 2026-08-11 建立（用户需求 3）：**每次金价分析输出格式完全一致**，任何板块不得整体省略。
> 对齐 `skills/gold-analysis-pipeline/SKILL.md` 的分析输出模板（九步管线），本文件补充具体的标题、表格列、emoji 与空态规则。

---

## 空态规则（核心）

- **每个板块必须输出标题**，无数据时写 `（本期无触发）` / `（本期无违规）` 等占位，**禁止整块省略**。
- 方向 emoji 固定：🟢 看多 / 🔴 看空 / ⚪ 中性
- 信号强弱：🟡（弱）/ 一般不加（中）/ 无需（强，用文字标）
- 决策：📌 | Agent：🐮/🐻/💼 | 违规：⚠️

---

## 板块固定顺序与格式

### 标题
```
# 🥇 金价完整分析 · YYYY-MM-DD HH:MM
```

### 行情概览引文（固定一行）
```
> 积存金 **¥958.81** | 国际 $4408/oz
```

### 1. 决策摘要
```
## 📌 决策: **持有** | 综合评分 +0.30 | 置信度 75%
建议仓位: 60%
止损: 921.63
止盈: —
```
方向词固定映射：`buy→买入 / sell→卖出 / hold→持有 / neutral→观望`。

### 2. 维度信号
```
## 维度信号
维度 | 方向 | 看多/看空/中性 | 均分 | 说明
```
用 `b.format_dimension_table()` 输出。**引用程序化表格汇总行，禁止手动数信号方向**（见 CLAUDE.md 信号维度计数规则）。

### 3. Agent 博弈
```
## Agent 博弈
🐮 **BullAgent** (信心 70%)
  ✓ 论据1
  ✓ 论据2
  ✓ 论据3
🐻 **BearAgent** (信心 65%)
  ✗ 论据1
  ✗ 论据2
  ✗ 论据3
```
无发言写 `（本期无多头发言）`。

### 4. 军规自查
```
## 军规自查
通过 20/32
⚠️ r011 警惕一边倒：信号方向分布...
（本期无违规）
```

### 5. Munger 模型
```
## Munger 模型
- **市场先生**: 理由...
- **安全边际**: 理由...
```

### 6. 画像匹配
```
## 画像匹配
✅ 兼容
- 约束说明...
```
`✅ 兼容` / `⚠️ 超出约束`。

### 7. 条件单审查
```
## 条件单审查
- co_xxx 保留 原因...
```

### 8. 后续关注
```
## 后续关注
- 美国CPI 08-12 20:30
```

### 9. 经验提醒
```
## 📚 经验提醒
- 提醒...
```

## 附：HTML 报告

分析完成后在终端末尾输出本地 HTML 报告地址（复制即可浏览器打开）：

```bash
python3 scripts/render_report_html.py
```

生成 `data/output/金价分析_YYYY-MM-DD.html` 并在终端打印 `file://{绝对路径}`。
