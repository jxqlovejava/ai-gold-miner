# 金价分析报告固定模板

> 2026-08-11 建立（用户需求 3）：**每次金价分析输出格式完全一致**，任何板块不得整体省略。
> 对齐 `skills/gold-analysis-pipeline/SKILL.md` 的分析输出模板（九步管线），本文件补充具体的标题、表格列、emoji 与空态规则。

---

## 空态规则（核心）

- **每个板块必须输出标题**，无数据时写 `（本期无触发）` / `（本期无违规）` 等占位，**禁止整块省略**。
- 方向 emoji 固定：🟢 看多 / 🔴 看空 / ⚪ 中性
- 信号强弱：🟡（弱）/ 一般不加（中）/ 无需（强，用文字标）
- 决策：📌 | Agent：🐮/🐻/💼 | 违规：⚠️
- 板块之间**不使用 `---` 分隔线**，仅用空行分隔（终端逐步输出亦同，2026-08-22 用户要求）

## 内部机制披露通俗化（2026-09-04 起，强制）

正文呈现涉及**机器内部机制披露**的行（⚠️ 复核/待查、方向冲突待复核、引擎推断 vs 日历写入、源层级冲突等骨架/scan 原文术语）时，禁止把机制术语行裸贴当结论。须在该行下补一行人话：

> 💡 通俗解读：<大白话讲清「谁和谁在冲突、各自立场、采信哪个、为什么」>

例：骨架项「初请失业金人数: 写入 neutral vs 推断 bullish 冲突」→

> 💡 通俗解读：系统内一个冒进推断（初请升→就业转弱→利多金）与保守判断（仅超预期 0.1 万）打架，采信保守方：差值属单周噪音，不足判方向。

### 1.0 行情回顾（2026-09-04 起，每次必含）

决策摘要后、主驱动前**固定回放近三日走势 + 日内分时走势**（用户要求：开头先讲清金价这两天怎么走、为什么，不只给结论）。数据表由程序生成（assemble 从 scan 块转贴），LLM 只补归因文段：

```
## 1.0 📈 行情回顾（三日走势 · 日内分时）
### 1.0.1 三日金价走势（国内 SGE ¥/g，与积存金同源联动）
09-02 收 971.13  +0.6%
09-03 收 971.20  +0.0%
09-04 现 968.29  -0.3%  ← 今日盘中
### 1.0.2 日内金价走势（SGE 三段: 夜盘/早盘/午后）
夜盘  958.20 → 965.40  +0.75% | 高 975.00/低 958.20 | 涨132分/跌107分
早盘  965.10 → 968.29  +0.33% | 高 968.50/低 963.20 | 涨45分/跌39分
午后  （未开盘）
（LLM 增量填充：三日逐日盘面概括与归因、日内各时段节奏解读——替换本行为各 1-2 句人话）
```

规则：
- **三日口径** = 国内 SGE Au99.99 元/克（scan 日线 tail3，与积存金同源联动），末 bar 为当日盘中则标「现 · ← 今日盘中」，涨跌 = 对前一交易日收盘。
- **日内三段** = 夜盘（前夜 20:00 起，含凌晨至 02:30）· 早盘（09:00-11:30）· 午后（13:30-15:30）；每段给 起→收涨跌%、段内最高/最低、上涨vs下跌分钟；未开盘段标「（未开盘）」。
- **职责分工**：数据表由 scan/assemble 程序生成，**LLM 只替换归因占位行为 1-2 句人话**（逐日概括 + 时段节奏解读），禁止改程序表列；归因须结合近期事件结果/主驱动素材，不臆造无来源原因。
- 空态：不足三日/无日内分时数据写占位行，板块标题不省略。
- 放置：`## 1.0` 固定插在 §1 决策（止盈行）与 §1.1 主驱动之间，编号不重排后续 1.1/1.2。

### 1a. 主驱动因素（2026-08-21 起，每次必含）
**每次分析必须显式回答「本次金价涨跌的主要驱动因素是什么」**（用户要求），格式：
```
## 1.1 🔍 主驱动因素
> 一句话: <第一性主驱动>

| 排序 | 驱动 | 性质 | 传导链 | 可预见性 |
|------|------|------|--------|---------|
| 1(主) | ... | 流动性/地缘/数据/情绪 | ... | 日历可见/突发政策/不可预见 |
```
规则：
- 主驱动判定方法：与价格拐点**同日发生**+**传导链最短**+**有量价佐证**（利率/资金流数据）的事件。
- 必须标注**可预见性**（日历事件 vs 日历外突发），日历外驱动须评估是否需要补监控。
- 无明确驱动（纯技术波动/缩量漂移）时写「无单一主驱动，属<震荡/漂移>型行情」。

### 1a-2. 一阶/二阶传导权重规则（2026-08-21 起）
当一阶传导与二阶传导**方向相反**时（如：回购->利率降->利多金价 vs 回购->通胀预期->联储鹰派->利空金价）：
- **短期方向判定（1-2周）以一阶传导为准**，二阶传导只作时间衰减后的风险标注，不得用二阶否决一阶方向。
- 二阶传导兑现需要明确的催化剂日期（如杰克逊霍尔/FOMC），在催化剂前不得将二阶计入主概率权重。
- 背景：2026-08-20 清仓决策用「回购或逼沃什加息」的二阶风险压过「回购压低实际利率」的一阶正向，错过 +1% 延续段（机会成本小，但暴露框架权重错误）。

### 1b. 金价目标区间预测（综合分析结论必含，2026-08-11 起）
**每次分析必须预测未来涨跌幅度**——分情景给出积存金目标区间（元/g），格式：
```
## 1.2 🎯 金价目标区间预测（未来 1-3 个月）
当前价 ¥958.81 | 对应 XAUUSD $4,408/oz

| 情景 | 概率 | 触发条件 | 积存金目标区间(元/g) | 对应 XAUUSD | 传导链(直接/二阶+时间尺度) |
|------|------|---------|---------------------|------------|---------------------------|
| 看多突破(先冲后落) | 20% | 停火破裂+央行购金延续 | **950-965(短期脉冲)/918-928(中期回落)** | $4,380-4,450 | 利多:避险溢价冲高(short-term)｜利空:油价→通胀→联储→实际利率↑回落(medium-term) |
| 高位震荡 | 50% | 停火拖延+数据温和 | 928-950 | $4,260-4,380 | 中性:多空博弈,冲高乏力+回落有撑(medium-term) |
| 回调修正 | 30% | 停火续约→溢价回吐 | 910-928 | $4,180-4,260 | 利空:溢价回吐(short-term)｜利多:央行购金/避险承接(medium-term) |
```
规则：
- **区间必须基于当前价推导**（突破关口的下一档心理位 / 支撑位 / 历史波动幅度），不凭感觉。
- 每情景给出**概率**（合计=100%）与**触发条件**（事件/资金/技术确认）。
- 参考档位：心理整数关口（950/1000/1100/1200 元/g）、20日高点、ATR 移动止盈位、成本净保本价。
- 预测与交易建议联动：看多区间冲关 → 条件单上移；回调区间 → 低吸档承接。
- **传导链列强制（r035）**：地缘/油价驱动情景必须同时写利多+利空传导并标注时间尺度（短期脉冲 vs 中期回落），只写单层传导 = 遗漏二阶效应，禁止。无地缘/油价驱动时写「（无地缘/油价驱动）」。

### 2. 维度信号
```
## 2. 维度信号
维度 | 方向 | 看多/看空/中性 | 均分 | 说明
```
用 `b.format_dimension_table()` 输出。**引用程序化表格汇总行，禁止手动数信号方向**（见 CLAUDE.md 信号维度计数规则）。

**维度逐项明细（2026-08-24 起强制）**：表格后按 `### 2.1` ~ `### 2.8` 编号逐维输出明细，**小节顺序 = 维度表行序**（dimension key 字母序：事件驱动 2.1 → 基本面 2.2 → 监控触发 2.3 → 消息面 2.4 → 情绪面 2.5 → 聪明钱 2.6 → 技术面 2.7 → 缠论结构 2.8）。0 信号维度保留标题写 `（本期无触发 / 数据缺失）`。

**明细必须 1:1 转贴 scan/骨架程序化表格（2026-08-27 起强制）**：2.1-2.8 各小节以**表格**形式逐行转贴当日 `scan_report`/骨架同名小节（2.1 事件日历表 / 2.2 基本面指标表 / 2.3 监控触发·已触发+观测中表 / 2.4 消息面信号表+最近新闻表 / 2.5 情绪面指标表+信号表 / 2.6 聪明钱子项表 / 2.7 技术面指标表+信号表 / 2.8 缠论结构块），**禁止压缩成散文段落、禁止把多行信号合并进一段话**（事故 2026-08-27：单次输出把 2.3-2.8 压成散文，绕过本小节排版规则）。落盘模式与单次模式同规则。

**技术面必含「🀄 缠论结构」子板块**（2026-08-12 起强制，编号 2.8 固定最后，见 SKILL.md 2.2）：
```
🀄 缠论结构（600天窗口 / 397根日线）：
- 结构：X 笔 + Y 中枢（ZG=… / ZD=… / ZZ=…），状态=形成/未形成
- 买卖点：缠论X买/卖（方向, score）— 日期@价位, 置信度 N%
- 当前位置：价格处于中枢上/下/内, 结构偏多/空
- 映射：X买 → 分批建仓锚点参考 / X卖 → 减仓止盈参考
```
- 无中枢/无买卖点时写 **「（本期无触发）」**，板块标题不省略。
- 数据源必须 `SpotGoldFetcher().fetch(days=600)`；积存金短窗口（<100根日线）无法形成结构，禁止用作缠论输入。
