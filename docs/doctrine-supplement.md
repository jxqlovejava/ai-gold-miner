# 投资军规补充（公开版）

> 来源：基于格雷厄姆《聪明的投资者》防御型投资原则，适配黄金投资场景
> 关联：[`CLAUDE.md`](../CLAUDE.md)（r001-r015 军规体系）、[`data/personal_rules.md`](../data/personal_rules.md)（个人实战 p 系列）

本文档收录与 r001-r015 互补的**通用**投资规则，不含持仓数字、止损价位等个人隐私信息。

## 补充规则

| ID | 规则 |
|----|------|
| p012 | **黄金仓位再平衡**：当黄金占总资产比例突破 55% 时启动预警，突破 60% 时 7 个交易日内强制减仓至 50% 以下；再平衡为一次性执行，不受 p013 间隔限制 |
| p013 | **分批建仓/加仓**：新建仓或单次加仓须分 ≥2 批执行，第二批最早于第一批执行日后第 5 个交易日执行，每批不超过该次计划加仓量的 50% |
| p014 | **安全边际加仓**：加仓前须给出估值区间（基于 DXY/实际利率/央行购金/金银比等多维度），当前价须处于估值区间下沿或回调支撑位；突破新高当日不追涨加仓 |

## 规则说明

### p012 再平衡

与 [`CLAUDE.md`](../CLAUDE.md) 中 r002（总敞口上限 80%）、r003（黄金占比 >50% 提示集中风险）形成层级关系：

- **r003**（>50%）：warn 级早期预警
- **p012**（55%/60%）：可操作阈值，60% 强制减仓
- **r002**（80%）：硬上限，任何情况下不得突破

### p013 分批建仓

避免在情绪驱动下一次性梭哈。适用于新建仓和单次加仓，不适用于再平衡（p012 为一次性机械执行）。

### p014 安全边际

黄金不产生现金流，无法使用 DCF 计算内在价值。本规则要求用多维度信号构建估值区间，只在区间下沿或关键支撑位附近加仓，不为追热点支付过高价格。

## 何时引用

在运行金价分析 pipeline、输出交易建议时，应将这些补充规则与 r001-r015 一并纳入 `DoctrineChecker` 审查。
