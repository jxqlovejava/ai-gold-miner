# Learning: 数据温和≠趋势确认的双向纪律（3天禁加仓 r033 升级 + 震荡止盈 r034 新增）

Date: 2026-08-14
Trigger: 8/13 CPI 核心 +2.5% 温和 + 8/14 初请中性后，金价进入高位震荡（920-970）；RSI 78 近超买 + COT 聪明钱 -12.2% 流出 + 投行共识看空 + 持仓浮盈 +1.0%，报告仍「持有不动」死扛等再涨；今晨 ATR 936.36 才机械卖出半仓（≈净保本 937.38），浮盈回吐殆尽。

## 学到的规则

1. **温和数据落地后 3 天(72h)内禁止任何加仓（r033 升级，绝对时间盒）**
   - 市场对温和/符合预期的数据已预先定价，落地≠方向确认
   - 原 r033（2026-08-13）只禁"24h 内连续追买"，且"有趋势确认可豁免"
   - 2026-08-14 用户明确：**数据温和落地后 3 天内不要有任何加仓动作**——趋势确认不构成豁免，须等市场消化
   - checker：`data_event_recent_72h and data_landed_mild → 任何 add 都警告`

2. **温和数据 + 多空博弈震荡期，盈利机动仓应主动部分止盈，不"死扛等再涨"（r034 新增）**
   - 触发（全部满足）：近48h重大数据温和落地 + 距20日高点<3% + 聪明钱流出(COT/投行/大单) + 已有浮盈
   - 动作：机动池高抛 ≥1/3（或 p010 减半）、核心池最多减 1/4；**不等 ATR 破位才动作**
   - 与 r033 互补：r033 管「温和不追买」，r034 管「温和震荡不死扛」

3. **PM 决策必须把「主动减仓」当一等公民选项**
   - 结构性缺陷：PM 只在「加仓/持有」间选择，减仓只留给机械触发（ATR 破位）
   - 昨天 Bear agent 已明说「机构在派发」，但 PM 无 reduce 路径可选 → 输出「持有不动」是结构必然，不是判断失误
   - 修复：SKILL.md 第七步新增 r034 主动止盈评估——四条件齐时不得只选持有，须显式评估部分止盈

4. **ATR 减半线必须预挂卖出条件单（r017 强执）**
   - 「跌破 X 减半」若只靠「监测 + 手动执行」，跌破时情绪死扛就错过
   - 8/14 事故：ATR 线 939.27 未预挂卖出单（8B 表只有两档限价买单 880/918），拖到 936.36 才机械触发卖半仓
   - 修复：SKILL.md 第八步强制——凡给出 ATR 减半线，必须预挂卖出条件单，禁止手动执行

## 对当日结论的影响

8/14 报告「持有不动」在 r034 视角下应改为「机动池部分止盈」：当时现价 946.67、距20日高点965仅1.9%（<3%）、RSI 78、COT -12.2%、净浮盈+1.0%，五条件全命中。今晨 ATR 936.36 卖出半仓 ≈ 净保本价，只保住本金未锁利润——正是「机械底线保本 vs 主动止盈锁盈」的差别。

## 补充：小克数机动仓「条件单 vs 监控提醒」的边界（2026-08-14 追记）

> 与上文「ATR 减半线必须预挂卖出条件单（r017）」看似矛盾，实为同一纪律在不同仓位的应用分级。

- **大克数机动仓（≥10g）**：必须预挂卖出条件单（r017 强执）。跌破即自动减，避免情绪死扛。
- **小克数机动仓（<10g，如本次 7.13g）**：不挂自动卖出条件单，改 `adaptive_gold_monitor.py` 908 破位微信提醒 → 人工决定。
  - 理由：7.13g × 0.4% 卖出手续费 ≈ ¥26，摩擦 > 保护；机械减半后只剩 3.5g 无实质意义（p010 <1g 守卫精神延伸）。
  - 补充防线：硬止损 654 兜底核心仓 + 监控 908 破位提醒兜底机动仓。
- **判定标准**：以「减半后剩余克数是否仍有操作价值」为准，而非只看 ATR 线本身。≤5g 的减半动作基本无意义，用监控提醒替代自动单，成本更低、不制造操作噪音。
